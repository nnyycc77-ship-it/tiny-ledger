# MCP server tools

One page per tool of the recall check MCP server, in the order the
server lists them. Each page states what the tool answers, its source
and its price, and quotes the tool's own `tools/list` description.
Going live on MCPize still waits on the owner's redeploy step in the
[redeploy runbook](../mcpize-redeploy-runbook.md).
