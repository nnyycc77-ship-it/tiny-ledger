AgentTab proof

Read only. This page reads the AgentTab contract's own events from an Arc RPC endpoint and lists every tab, how it settled, and the amounts, with a link to each transaction on the explorer. No wallet is needed. Every event name and field below is taken from contracts/AgentTab.sol; the written proof is in PROOF.md.

Event signatures and topic hashes used by this page

Each signature is copied from the contract. The topic hash is keccak256 of the canonical signature, computed here in the browser; it is what the RPC log filter matches on, so a wrong signature would return nothing rather than something else.
