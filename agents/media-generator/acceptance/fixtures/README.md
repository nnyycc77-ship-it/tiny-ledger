# Acceptance fixtures: media generator

SYNTHETIC brief for `../acceptance.py` (issue #124).

`brief-samples.json` holds the job posting's four sample scenarios as one
brief:
- three square images of a ceramic mug on a wooden table;
- an 8 second vertical video of coffee being poured into a cup;
- a 30 second voiceover from a provided script, warm female voice;
- an image of a well-known celebrity holding the product (to be declined).

It adds one request for a copyrighted character, to be declined under the
posting's rules. The voiceover script was written for this test, and no
real person or brand is named. Only the agent's offline stub providers
run, so every file is a placeholder, as the agent's own report states.
